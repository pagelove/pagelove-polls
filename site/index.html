How it works on Pagelove

Polls by Pagelove has no server code. The HTML documents are the application; the platform supplies storage, validation, permissions and real-time updates.

1

Create is a POST to a template

The form posts to /templates/new-poll.html. Liquid renders a complete poll page whose <base href> names its own URL; the server stores it there and redirects you to it.

2

Voting is a POST of one <tr>

Your availability is a table row appended with Range: selector=#responses. Editing is a PUT on that row, withdrawing is a DELETE. No API layer in between.

3

Rules and shapes guard the page

Deny-by-default AuthorizationRules open exactly the elements the app needs. A closed ShapeConstraint rejects any row that isn't a name plus vote cells.

4

Live updates via Server-Sent Events

Each poll page subscribes to its own mutation stream. When someone else votes, their row lands in your grid without a refresh.
